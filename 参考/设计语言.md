# 校园墙 · 设计语言（基于 Kimi 设计方案）

## 一、视觉风格

### 风格定位
**「阳光透过百叶窗洒在桌面上」的温暖手绘感 Galgame 风格**

融合两种方案：
1. **kimi1**（Galgame 无厘手绘版）— 涂鸦背景、纯CSS角色立绘、弹跳对话气泡、像素风字体
2. **kimi2**（温暖手绘版）— 奶油色系、GSAP 滚动动画、毛玻璃卡片、书信体排版

### 设计语言核心

1. **毛玻璃（Glassmorphism）** — `backdrop-filter: blur(20px)` + 半透明白色边框
2. **手绘感** — 不规则边框、旋转偏移（`rotate(-2deg)`）、涂鸦背景
3. **对话气泡布局** — 帖子以气泡形式展示，含尾部引线
4. **序列式加载动画** — Galgame 风格逐字浮现
5. **滚动触发动画** — GSAP ScrollTrigger 驱动的淡入上浮
6. **视差光晕** — 多层模糊光晕缓慢浮动

## 二、UI 组件规范

### 导航栏
- 固定顶部居中，毛玻璃背景
- 圆角 24px，悬浮在页面上方
- 品牌 Logo + 导航链接 + 登录/注册按钮

### 侧边导航
- 毛玻璃圆角卡片，sticky 定位
- 每个导航项含图标 + 文字
- 激活态左侧有粉色竖线指示
- hover 时背景淡粉色

### 子站卡片
- 不规则圆角（`border-radius` 50% 30% 等变化）
- hover 时上浮旋转
- 含封面渐变色块 + 名称 + 简介
- 3列网格布局

### 帖子卡片
- 对话气泡式设计，左侧引线（SVG 曲线）
- 头像 + 作者 + 时间 + 标题 + 预览 + 图片
- 底部操作栏：点赞/评论/收藏/分享
- 交错颜色背景（粉色/黄色/紫色循环）

### 按钮
- 圆角 50px，粗边框（3px）
- 粉/黄/紫/霓虹四种配色
- 阴影偏移效果（`box-shadow: 4px 4px 0`）
- 点击时下沉 + 缩放动画

### 标签/分类
- 胶囊式圆角
- 激活态粉色渐变背景
- hover 上浮

## 三、动画系统

### 加载动画
1. Logo 淡入上浮（0.8s）
2. 逐行打字机效果（3 行文本）
3. 加载完成后页面淡入

### 滚动动画（GSAP ScrollTrigger）
- 所有 `.reveal` 元素：淡入 + 上移 30px（阈值 85%）
- 背景光晕：缓慢视差滚动（scrub: 1）
- 卡片交错延迟（`delay: i % 3 * 0.1`）

### 交互动画
- 角色立绘：鼠标视差跟随
- 对话气泡：鼠标视差跟随（不同因子）
- 点赞：弹性缩放（easeOutElastic）
- 选择按钮：点击缩放
- 子站卡片：hover 上浮 + 旋转

### 装饰动画
- 星星闪烁（`twinkle`）
- 云朵浮动（`float`）
- 圆点弹出（`popDot`）
- 呆毛摇摆（`ahogeWiggle`）
- 眼睛眨眼（`blink`）
