## 1. 账号与登录

- **注册**：点击右上角「注册」，填写用户名、邮箱、密码（至少 6 位）。
- **登录**：输入用户名/邮箱 + 密码即可登录，Token 有效期为 7 天。
- **找回密码**：在登录框点击「忘记密码」，输入注册邮箱。若未配置邮件服务，系统会在开发模式下直接显示重置 Token，携带 Token 访问 `/reset-password?token=xxx` 完成重置。
- **修改资料**：登录后进入个人主页 →「编辑资料」，可修改用户名、简介、个性签名、称号。

## 2. 子站（兴趣圈子）

子站是平台的核心组织单位，类似「圈子 / 社团」。

### 发现与加入
- 首页「子站市场」浏览全部子站，支持按 **分类**（如 学习/情感/兴趣）、**标签**、**排序**（最新/最热/帖子最多）筛选。
- 点击子站卡片进入详情，点击「加入」成为成员。

### 发帖
- 在子站详情页点击「在此子站发帖」，选择帖子类型（图文/链接/投票）。
- 注意：私密子站仅成员可发帖；「仅站长可发帖」的子站只有站长能发帖。

### 站长管理（子站创建者 / 全局管理员）
进入子站详情 →「管理子站」：
- 修改名称、简介、图标、**分类**（支持 `父分类/子分类` 层级）、封面图（可上传）、公告
- 切换「公开 / 私密」、开启「仅站长可发帖」
- **转让子站**：输入新站长用户 ID 完成交接
- **删除子站**（危险操作，需二次确认）
- 成员管理中可**移除成员**（站长本人不可被移除）

## 3. 发帖与互动

### 帖子类型
| 类型 | 说明 |
|------|------|
| 图文 | 文字 + Markdown，可上传图片 |
| 链接 | 分享外链 |
| 投票 | 自定义选项，读者可投票并查看结果 |

### 互动操作
- **点赞 / 收藏**：帖子底部操作栏。
- **评论**：支持回复，评论可点赞。
- **匿名发布**：发帖时勾选「匿名」，其他人看不到你的真实身份（作者本人和管理员可见）。
- **置顶/加精**：仅管理员可操作（在帖子编辑中）。
- **编辑历史**：作者或管理员可查看帖子的历史版本（点击帖子右上角「历史」图标）。
- **举报**：任何用户可举报违规内容（选择原因 + 补充说明），由管理员处理。
- **分享**：支持系统分享面板或复制链接。

## 4. 二手交易

- **发布闲置**：点击「发布闲置」，填写商品名、描述、售价、原价、成色、分类、联系方式。
- **浏览与筛选**：按分类（数码/教材/生活/服饰/其他）筛选，或关键词搜索。
- **联系买家/卖家**：点击商品卡片查看详情弹窗，获取联系方式自行联系。

## 5. 恋爱情报

- **人物墙**：浏览已发布的恋爱档案（昵称、性别、年龄、院系、爱好、期望对象），可向心仪的人匿名发送情报。
- **情报链接**：查看收到的表白/留言；「发送新情报链接」可通过用户 ID 发起。
- **任务板**：发布恋爱相关任务（如帮忙打听、组队等），可设置赏金（金币）。
- **我的档案**：填写自己的恋爱档案，便于被他人发现。

## 6. 树洞爆料

- 完全匿名发布内容（无需登录也可浏览）。
- 支持点赞、评论、热门/最新排序。
- 热门内容会获得「热门」标识。

## 7. 签到与成长

- **每日签到**：访问 `/checkin` 点击「签到领奖」。
  - 基础奖励：10 金币 + 2 积分
  - 连签加成：每天 +5 金币，最多 +35
  - 连签 7 天可达 45 金币 + 14 积分
- **签到日历**：按月查看打卡记录，绿色标记为已签到。
- **等级与经验**：发布、互动、签到会积累经验，个人主页显示等级进度条。

## 8. 积分商城

用金币/积分兑换专属道具：

| 道具 | 效果 |
|------|------|
| 初学者徽章 / 学霸徽章 / 恋心徽章 | 身份装饰 |
| VIP 头像框 | 专属头像装饰 |
| 改名卡 | 修改一次用户名 |
| 置顶卡 | 帖子置顶 |
| 匿名发帖 | 匿名发布一次帖子 |
| 彩虹昵称 | 7 天彩虹色昵称 |

在商城「我的订单」中点击「使用」道具，按提示输入参数。

## 9. 个人主页与社交

- **个人主页** `/profile/<id>`：展示头像、昵称、身份组徽章、称号、个性签名、金币/积分/等级/连签，以及：
  - 帖子 tab
  - 加入的子站 tab
  - 赞过 tab（仅自己可见）
  - 收藏 tab（仅自己可见）
  - 粉丝 / 关注 tab
- **关注**：在他人主页点击「关注」，被关注者的新动态会推送给你。
- **通知**：`/notifications` 查看点赞、评论、关注等通知，支持未读标记。

## 10. 管理后台

访问 `/admin`（仅系统管理员）：

| 标签页 | 功能 |
|--------|------|
| 仪表盘 | 全站数据统计 + 7/14/30 天增长趋势图 |
| 用户管理 | 修改角色（user/admin）、身份组、金币、积分、等级 |
| 子站管理 | 查看/删除子站 |
| 帖子管理 | 查看、置顶、删除帖子 |
| 身份组 | 查看/创建身份组 |
| 商城管理 | 创建商城商品 |
| 举报中心 | 处理用户举报（确认违规/驳回） |
| 公告管理 | 发布/隐藏/删除全站公告（公告显示在首页顶部） |
| 操作日志 | 后台操作审计记录 |
